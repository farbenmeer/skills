# Spec Reconciliation based on Code changes

Reflect the current session.
Use git to find the current (unstaged) code changes.
If given a specific commit hash, use it to find code changes in that commit.

/plan the changes to the spec documents necessary so the spec (all markdown files in the spec-directory) reflects the current codebase including the unstaged code changes.

When the plan is approved, apply the changes to the spec documents.
